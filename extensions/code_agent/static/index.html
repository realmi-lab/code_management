문구 비교

?
새 문구를 등록 목록과 비교해 시간·숫자·이후/이내·변수 차이를 확인합니다. 유사 문구가 있어도 재사용이 확정되지는 않습니다.

기획서 검토

?
코드번호·미등록 여부·폐기 상태와 문구의 조건 차이를 줄별로 검토합니다. 최대 30줄까지 한 번에 검토합니다.

전체 코드

?
번호와 문구는 원문 그대로 표시합니다. 코드번호를 누르면 상세를 볼 수 있습니다.

검색
?
키워드 검색은 코드번호와 단어를 기준으로 찾습니다. 의미 검색은 표현이 달라도 뜻이 비슷한 알림을 찾으며, 로컬 임베딩은 별도 API 키가 필요 없습니다. 검색 방식을 바꾸면 인덱스를 다시 준비해야 하고, 일반 문서도 다시 인덱싱해야 합니다.
