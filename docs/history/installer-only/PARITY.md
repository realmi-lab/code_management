# 원본 동일성 범위

## 판정 기준

고정 커밋의 전체 파일·내용·Git 파일 모드·symlink를 tree 해시로 검증한다. 핵심 파일 몇 개만 복사하고 전체 기능을 재사용했다고 판정하지 않는다.

검증되는 전체 tree: `6e5ebcef24cfc575f5659329d946cc56c103c9ca`.

**현재 전달 시점에는 전체 소스 다운로드 전이므로 동일성 검증 완료라고 판정하지 않았다.** 설치 도구의 정확성은 합성 로컬 Git 저장소와 비교하여 검사했다.

## 원본에서 바꾸지 않은 것

원본 애플리케이션의 검색 알고리즘, 관리자 화면, 모델 기본값, 가드레일 정책을 이 패키지에서 재작성하거나 단순화하지 않았다. 원본이 갖고 있는 미완성·버그·제약도 자동으로 해결되지 않는다.

이전에 검토한 모델 설정과 인스턴스 연결, 문서 삭제 시 인덱스 정리, 캐시 구분, OpenAI 호환 스트리밍/대화 이력 등의 항목도 별도 수정·검증 없이 해결됐다고 보고하지 않는다.

## 별도 배포 코드에서만 바꾼 것

외부 공유 인프라 제거, 로컬 포트 제한, DB 초기화·마이그레이션, 인덱싱 워커·Beat, 볼륨 공유, 모델 캐시, 빌드 시 프론트 API 주소, 헬스체크, Langfuse 서비스 초기화, 비밀값 생성을 추가했다.

이런 배포 구성의 변경은 실행에 필요한 보완이며, 원본과 배포 토폴로지까지 바이트 단위로 같은 것은 아니다. 컨테이너 이미지·외부 모델의 실행 검증을 대신하지 않는다.

## 기존 카탈로그의 위치

`catalog_legacy/`는 이전 앱의 보존본이다. 기본 전체판 실행에서는 사용하지 않는다. `--legacy`는 별도 서비스로 같이 실행하는 선택사항이며, 공통 로그인·원본 검색 사용·원본 프론트 통합을 의미하지 않는다.

최종 기획자용 통합판이 필요할 때도 원본 RAG를 유지하고 알림 코드 전용 DB/원문 출력/승인 흐름을 확장 모듈로 연결해야 한다. 이는 아직 구현 완료된 항목이 아니다.
