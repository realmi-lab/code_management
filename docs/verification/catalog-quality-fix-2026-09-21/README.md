# 첫 수정본의 실제 회귀 검사

원래 68문항 중 실패했던 2·5·7·27·67번을 각 두 번, 새 demo 대화에서 실행했다. 원래 68문항 결과는 변경하지 않았다.

- 10회 중 8회 응답·GOOD, 2회 형식 오류(HTTP 502).
- 첫 반복의 7·67번은 `AI 응답 형식이 올바르지 않아 저장하지 않았습니다.`로 차단됐다. 두 번째 반복은 둘 다 성공했다.
- 성공한 8회는 수치·충실도·근거 검증을 통과했다. 평균 AI 채점 98.375점이며 생성 모델과 동일한 모델이 별도로 채점했다.
- 실제 목록, 샘플 원문, 설정, 제공자는 검사 전후 동일했다.

당시 오류 응답과 호출 기록은 보존했지만 파싱 실패한 생성 답변 전문은 저장하지 않았다. 따라서 구체적으로 잘못된 JSON 문법인지 속성/타입 불일치인지는 복구할 수 없다. 별도의 두 설명 생성 재현도 정상 통과해 원문을 복구하지 못했다.

이 결과를 성공으로 덮어쓰지 않았다. 이후 text 문자열의 줄바꿈 이스케이프를 명시하고, 스키마 오류도 같은 근거로 최대 한 번 재생성하도록 보완했다. 최종 수정본은 [별도 보고서](../catalog-quality-fix-final-2026-09-21/README.md)에 기록한다.

근거: [응답](results.json), [요약](summary.json), [검증 이벤트](validation-trace.json).
