# 알림 코드 68개 실제 품질 평가

현재 로컬 앱 + 분리된 합성 DB 평가입니다. 공공 문서 68개 Q&A를 사용하는 원본 평가와 동일한 데이터셋이 아닙니다.

| 지표 | 결과 |
|---|---:|
| 평가 질문 | 68 / 68개 |
| AI 채점 평균 | 89.8 / 100 (63개 채점 성공 기준) |
| GOOD 판정 (70점 이상) | 63 / 68개 |

| 답변 오류 / 채점 오류 | 5 / 0 |

## 평가 조건

- 로컬 E5 + 하이브리드 검색 + 한국어 리랭커, 초기 후보 20개/최종 8개. HyDE와 멀티쿼리 OFF. 설정 원본은 `settings.json`.
- 실제 검색과 대화 API를 사용합니다. 답변은 Command Code 경유 DeepSeek이며 채점도 동일 모델의 별도 호출입니다. 독립 모델 평가가 아니므로 자기평가 편향 가능성이 있습니다.
- 원본의 100점 루브릭(정확성40/완전성30/관련성20/무해성10)과 키워드 추출 코드를 재사용했습니다. 70점 이상을 GOOD으로 집계합니다.
- 원본의 검색 적중 기준(score>0.3) 대신, 사전에 정한 정답 코드가 반환 후보 안에 있는지 검사합니다. 따라서 원본의 적중률 수치와 직접 비교하지 않습니다.
- 키워드 재현율은 코드·원문·메뉴·조건으로 구성한 정답과 실제 AI 설명을 비교합니다. API 실패는 재현율0/검색미적중/GOOD아님으로 포함합니다. 채점 평균은 실제 유효 점수가 나온 건만 포함하고 채점 수를 함께 표시합니다.
- 12개 직접 작성 질문 + 56개 메뉴/조건 템플릿 질문. 메뉴·조건이 질문에 주어지므로 일반적인 자유 질문보다 쉬울 수 있습니다. 결과를 보고 정답을 바꾸지 않았습니다.
- 평가 중 모델·검색 설정은 변경하지 않았습니다. 대화는 demo 스코프에만 생성합니다. 운영 데이터는 삽입하지 않습니다.
- 2개 요청을 동시 실행했으므로 응답 시간은 동시 실행 환경의 관측값입니다. 과거 단일 요청 시간과 직접 비교하지 않습니다.

운영 목록 조회값/버전 보존: True. 반환 후보 원문 일치: True.
