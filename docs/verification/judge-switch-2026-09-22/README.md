# 판정 모델 전환 실측 (2026-09-22)

대화 답변의 충실도·근거 판정 단계를 다른 모델로 바꿨을 때의 속도와 판정 품질을 같은 입력으로 비교했다. 모든 실행은 이 Mac의 실제 서비스(demo 목록 279건, 합성 데이터)와 실제 모델 호출이며, production 목록은 건드리지 않았다.

## 파일

| 파일 | 내용 |
|---|---|
| `before.json`, `before.log` | 전환 전(DeepSeek V4.1 Flash low가 판정) 실제 대화 턴 10건. `measure_turns.py`가 API에 턴을 보내고 Langfuse 스팬에서 단계별 시간을 읽었다 |
| `negative-bench.log` | 실제 파이프라인 형식의 정답·오답 판정 벤치. 일회용 컨테이너에서 `CatalogSafety.validate`를 직접 호출했고 Apple 온디바이스 판정과 DeepSeek 판정을 각 변형당 3회 실행했다 |
| `after-apple.json`, `after-apple.log` | Apple 온디바이스 판정을 실제 서비스에 반영한 뒤의 대화 턴 |
| `after-glm.json`, `after-glm.log` | `z-ai/glm-5.3-flashx`(effort none) 판정으로 바꾼 뒤의 대화 턴 |

## 전환 전 기준선 (DeepSeek 판정, 10턴)

질문은 68문항 세트의 1·2·5·7·27·67·3·9·12번과 무관 질의(날씨) 하나다. 10건 모두 200 응답이었고 차단은 없었다. 정답 순위는 27번(SM-1005)만 2위, 나머지는 1위였다. 한 턴 전체는 12.4~31.9초, 충실도 판정 2.8~21.4초, 근거 판정 2.9~14.2초였다.

## Apple 온디바이스 모델 사전 탐색 (워커 직접 호출, 합성 근거 1쌍)

| 방식 | 정답 | 오답(60초로 변경·이메일 문장 추가) | 비고 |
|---|---|---|---|
| 자유 서식, 지시 없음 | 형식 불량 3/3 (distortions 목록이 길어져 verdict 줄 없음) | 충실도 0.9 FAITHFUL로 통과 3/3 | 근거 판정은 한 줄에 항목을 몰아 써 StrictJudge가 읽지 못함 |
| 자유 서식 + 형식 지시 | 형식 불량 3/3 | 통과 3/3 | 코드 펜스로 감싸 출력 |
| 자유 서식 + 엄격 지시 | 0.5로 차단 3/3 (위양성) | 차단 3/3 | 비수치 추가 문장 변형은 0.9로 통과 |
| 스키마 강제(guided generation) | 0점 차단 3/3 (위양성) | 차단 3/3 | 형식은 3/3 유효 |

## 실제 파이프라인 형식 벤치 (`negative-bench.log`)

근거는 demo 목록의 EX-0104·EX-0105·EX-0101 실제 행이며, 답변은 EX-0104 원문을 그대로 옮긴 정답과 그 변형이다. 변형당 3회.

| 변형 | 기대 | Apple 온디바이스(스키마 강제) | DeepSeek V4.1 Flash(low) |
|---|---|---|---|
| 정답(원문 그대로) | 통과 | 차단 3/3, 3.3~4.2초 | 통과 3/3, 3.8~8.0초 |
| 정답 두 코드 나열 | 통과 | 차단 3/3 | 차단 3/3 (위양성), 10.9~31.5초 |
| 30초를 60초로 변경 | 차단 | 수치 검증 단계가 차단(모델 호출 전) | 동일 |
| 문서에 없는 문장 추가 | 차단 | **통과 3/3** | 차단 3/3, 7.0~10.2초 |
| 메뉴 값 바꿈 | 차단 | 차단 3/3 | 차단 3/3 |
| 코드 번호 바꿈 | 차단 | 차단 3/3 | 차단 3/3 |

근거 형식을 설명하는 시스템 지시를 판정 전송에 붙인 추가 실험(워커 직접 호출, 실제 형식 프롬프트, 각 3회)에서는 정답과 두 코드 정답이 모두 통과했지만, 문장 추가 변형은 근거 판정 1.0으로 여전히 통과했고 충실도 판정은 스키마 디코딩 실패(decodingFailure)로 끝났다. 메뉴 변경 변형도 근거 판정이 디코딩 실패였다. 디코딩 실패는 앱에서 502로 차단되므로 조용히 통과하지는 않지만 판정이 아니다.

## 결론

온디바이스 모델은 정답을 차단하거나(지시 없음) 문서에 없는 문장을 통과시켜(형식 지시 있음) 현재 판정보다 검증이 약하다. Apple 경로는 코드·테스트·문서를 갖춘 선택 기능으로 남기되 기본값은 끈다. 표본은 답변 변형 6종 × 3회이며 위양성률 추정이 아니다.
