# 합성 알림 코드 200건 검증

`examples/sample_code_catalog_200.xlsx`는 실제 회사 데이터가 아닌 합성 테스트 목록이다.

- 코드: `AT-2001` ~ `AT-2200`, 총 200건
- 사용중 190건 / 폐기 10건
- 영역: 본인인증, 회원가입, 로그인, 비밀번호, 원화·코인 입출금, 매수·매도, 주문, 자산, 보안설정, API, 이벤트, 알림, 고객센터, 프로필, 약관정책, 시스템공통
- 의도적으로 `30초 이후`/`30초 이내`, 3회/5회 실패, `{coin}`, 24시간/48시간 등 유사하지만 조건이 다른 예시를 포함한다.

검증 시나리오:

1. XLSX 파서가 200건을 오류·경고 없이 읽는다.
2. 미리보기에서 신규 200건으로 분류한다.
3. 커밋 후 전체 200건, 기본 검색 대상 190건(폐기 제외)을 유지한다.
4. `AT-2001`, `AT-2011`, `AT-2200`의 원문·상태·셀 위치를 보존한다.
5. `이미 가입된 휴대폰 번호` 질의에서 `AT-2011`을 관련 후보로 확인한다.
6. `30초 이후`와 `30초 이내`의 조건 차이를 비교 로직이 감지한다.
7. `48시간 출금 제한` 신규 문구 초안을 만들고 기존 `AT-2127`(24시간 제한)을 유사 후보로 확인한다.
8. 관리자 확인을 거쳐 샘플 신규 코드 `AT-2301`로 등록하는 흐름을 검증한다.

`integration_tests/sample_200_e2e.py`는 저장·가져오기·대화·비교·초안·승인 로직을 실제 코드로 실행한다. 외부 RAG 검색과 LLM만 네트워크/API 키 없이 반복 실행할 수 있도록 결정론적 테스트 대역으로 대체한다. 따라서 이 검사는 실제 OpenAI/PGVector/Nori 품질 측정이 아니다.

`integration_tests/test_sample_200.py`는 FastAPI의 실제 코드 카탈로그 가져오기 API에 위 XLSX를 업로드해 200건 미리보기·커밋·목록·정확 조회를 확인한다.
