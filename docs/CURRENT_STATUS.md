## UI 업데이트

현재 Taste 설정은 `DESIGN_VARIANCE: 8`, `MOTION_INTENSITY: 6`, `VISUAL_DENSITY: 4`입니다. 2026-09-17에 Taste Skill v2 기준 2차 정제를 적용했습니다. 기존 정보구조와 기능은 유지하면서 검색 영역을 핵심 workbench로 강화하고, 첫 결과는 dark forest identity pane으로 명확히 강조하며 후속 결과는 2열 구조를 유지합니다.

색상은 forest 단일 accent와 off-white/off-black 계열로 정리했고, 반경을 control 8px / surface 14px / dialog 18px로 통일했습니다. sidebar active state, 입력·버튼·표·dialog의 계층도 같은 토큰으로 정리했습니다. 기본 글자는 14px이며 모바일 1열과 `prefers-reduced-motion`을 유지합니다. 출처와 기준은 `UI_DESIGN.md` 참고.

사용자 요청에 따라 `[나가기]`, `[확인]` 등은 본문에 원문 그대로 표시합니다. 별도 버튼 미리보기는 사용하지 않습니다.

## 입력이나 별도 설계가 필요한 범위

- 실제 회사 코드 엑셀: 아직 받지 않았으므로 원본 양식과 실제 검색 정답 검증은 대기.
- 회사 번호 발급 규칙: 임의 설정하지 않음. 공식 기준은 엑셀 담당자.
- 조직 SSO, 사용자별 역할·승인자 감사와 부서 분리: 계정 체계와 조직 정책이 필요한 후속 확장.
- 다국어별 코드 관리, 서비스 코드 사용처 추적: 원본 필드와 연동 대상을 정한 뒤 별도 설계.
- 임베딩 모델/대규모 검색 인프라: 현재 AI 상황 검색에는 필수가 아니며 설치하지 않았음.
- Docker Local 자체 재부팅 이후 시작: `supervisord -c /shared/code_management/deploy/supervisor.conf`.
  시스템 인프라 시작 설정은 변경하지 않았음.

위 후속 확장을 포함해 모든 조직용 기능이 완성됐다는 뜻은 아닙니다. 현재 단일 사용자 기획자 업무 흐름의 미완성 부분을 연결한 상태입니다.
