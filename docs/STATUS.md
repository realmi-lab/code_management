# 현재 전달 상태 — 통합 확장판

기준일: 2026-09-18

**원본 RAG 연동과 기획자 대화형 코드 관리의 실제 소스를 작성하고 로컬 테스트를 수행했다. 사용자 Docker Local 배포 또는 실제 모델을 포함한 전체 스택 기동 완료는 아니다.**

| 항목 | 구현·검증 상태 |
|---|---|
| 원본 FastAPI 안의 코드 관리 API | 구현. 실제 확장 API·저장 로직 검사 통과 |
| 원본 JWT/계정 연결 | 원본 get_current_user 사용. 계약/구성 확인. 원본 JWT·Redis 라이브 검증은 미수행 |
| 원본 Next.js의 /codes | 추가 페이지·사이드바 패치 구현. TSX 구문 검사 통과. 전체 원본 Next 빌드는 미수행 |
| 대화 검색→비교→신규 초안 | 구현. 대화 문맥·후보 순서·재검색·초안·승인 흐름 검사 통과 |
| 원본 하이브리드 검색 연결 | 실제 원본 엔진을 import/call하는 어댑터 구현. 계약 대역으로 경로 검사. 실제 검색 모델 실행 미수행 |
| PGVector/Nori 카탈로그 인덱싱 | 별도 스냅샷·공유 chunk ID·버전 공개·재시도 제어 구현. PostgreSQL/ES 라이브 검증 미수행 |
| 엑셀/CSV 입력·원문·충돌 처리 | 실제 파서·API·DB 검사 통과. 실제 회사 엑셀은 제공받지 않음 |
| 관리자 등록·감사 | 실제 로직·API·대화 복원 검사 통과. 기본 모드는 엑셀에서 확정한 번호 확인 후 직접 입력 |
| 기존 설치 결함과 원본 연결 결함 | 패치 작성, 회귀 검사 통과. 원본 전체 버그를 고친 것은 아님 |
| 최신 통합/연동 테스트 | 83개 통과 |
| 설치 테스트 | 58개 통과 |
| 실제 localhost HTTP 테스트 | 10개 검사 통과. 인증·모델은 대역 |
| Chromium UI 테스트 | 14개 검사 통과. 로컬 파일 + 실제 API TestClient 브리지; 인증·모델·클립보드는 대역 |
| 원본 전체 소스 | 패키지에는 미포함. 설치 시 공식 고정 버전 수집·무결성 검사 |
| 실제 Docker/원본 전체/AI 모델 기동 | 이 환경에서는 미검증 |
| 사용자 맥/Docker Local 반영 | 수행하지 않음 |

이전 설치본 기록은 docs/history/installer-only/에 보존했다. catalog_legacy/의 코드/문서/과거 스크린샷을 이번 통합판의 실행 결과로 사용하지 않았다. 최신 증거는 docs/verification/ 및 TEST_REPORT.md를 따른다.
